Capstone Project

Tracking spring bird migration

This project combines eBird abundance estimates, BirdFlow movement models, and NEXRAD weather radar to map when and where migratory birds move through the region each spring.

Methods

Three complementary data sources, each answering a different part of the migration question.

Where

eBird Status & Trends

Weekly relative-abundance estimates show where each species is concentrated across the season.

How

BirdFlow routes

Movement models built from eBird data simulate likely individual migration paths.

When

Weather radar

Nightly NEXRAD radar captures real migration pulses, showing the timing and intensity of movement.

Findings

Key results and figures from the analysis.

Data & tools

  • eBird Status & Trends (Cornell Lab of Ornithology)
  • BirdFlowR
  • NEXRAD weather radar, processed with bioRad and vol2birdR
  • Analysis in R (sf, terra, dplyr, ggplot2); maps in ArcGIS Online
